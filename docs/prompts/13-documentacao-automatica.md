# Prompts: Documentação Automática

Prompt 1 — Gerar documentação automática com IA
---
Contexto: O projeto precisa de documentação técnica automática para ajudar na manutenção e na apresentação da solução.

Instrução para o assistente IA:
- Gere documentação automática para o código com o Swagger.
- Mantenha linguagem objetiva e aderente ao domínio canônico.

Saída esperada:
- Estrutura de documentação sugerida.
- Exemplos de docstrings, descrições de API e blocos de README prontos para uso.
