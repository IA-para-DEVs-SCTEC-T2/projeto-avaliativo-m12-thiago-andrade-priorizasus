# Prompts: Atualização do README

Prompt 1 — Atualizar `README.md` com diagrama, instruções e evidências
---
Contexto: O `README.md` final deve mostrar o projeto, orientar execução e reunir evidências úteis da implementação.

Instrução para o assistente IA:
- Gere uma atualização do `README.md` com visão geral do projeto, diagrama da solução, instruções de execução, principais decisões e links ou referências de evidências.
- Use linguagem direta e organizada por seções.

Saída esperada:
- Blocos prontos para inserir no `README.md`.
- Sugestão de seções para manter a documentação final clara.
