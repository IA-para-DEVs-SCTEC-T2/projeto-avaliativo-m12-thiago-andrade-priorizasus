# Prompts: Validação do Pipeline

Prompt 1 — Testar e validar pipeline
---
Contexto: O pipeline de CI/CD já foi criado e agora precisa ser testado para confirmar que executa corretamente.

Instrução para o assistente IA:
- Liste um passo a passo para validar o pipeline recém-criado, incluindo como simular falhas, conferir logs e verificar se os checks ficam verdes.
- Inclua critérios objetivos para considerar o pipeline aprovado.

Saída esperada:
- Checklist de validação do pipeline.
- Sugestões de correção para erros comuns de configuração.
