# Prompts: Entrega Final

Prompt 1 — Revisar checklist final e submeter links no AVA
---
Contexto: Após concluir o projeto, é preciso conferir todos os entregáveis e enviar os links corretos no AVA.

Instrução para o assistente IA:
- Monte um checklist final com todos os itens obrigatórios: repositório, quadro, branches, commits, documentação, testes, CI/CD, vídeo e evidências.
- Organize a resposta para facilitar a conferência antes do envio final.

Saída esperada:
- Checklist final pronto para uso.
- Lista de links que devem ser conferidos e enviados no AVA.
