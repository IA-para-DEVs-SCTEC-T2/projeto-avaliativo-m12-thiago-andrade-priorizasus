# Prompts: CI/CD com GitHub Actions

Prompt 1 — Configurar pipeline de CI/CD com GitHub Actions via IA
---
Contexto: O projeto precisa de um pipeline automatizado para validar build, testes e verificações de qualidade antes do merge.

Instrução para o assistente IA:
- Proponha um workflow de GitHub Actions para o repositório, incluindo etapas mínimas de build, testes e validações do projeto.
- Explique em quais eventos o pipeline deve rodar e como organizar os jobs.

Saída esperada:
- Exemplo de arquivo YAML para `.github/workflows/`.
- Explicação curta de cada job e gatilho do pipeline.
