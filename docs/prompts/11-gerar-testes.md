# Prompts: Suíte de Testes

Prompt 1 — Gerar suíte de testes com suporte de IA
---
Contexto: O código principal já existe e precisa ser coberto por testes automatizados para validar regras de negócio, integrações e cenários críticos.

Instrução para o assistente IA:
- Crie uma suíte inicial de testes para as regras mais importantes do sistema, priorizando casos felizes, casos de borda e validações negativas.
- Garanta que os testes reflitam os termos canônicos do domínio e os requisitos do Phase 1.

Saída esperada:
- Lista de classes de teste necessárias.
- Casos de teste com nome claro, cenário e expectativa.
