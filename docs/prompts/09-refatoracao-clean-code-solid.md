# Prompts: Refatoração com IA

Prompt 1 — Refatorar código com suporte de IA (Clean Code / SOLID)
---
Contexto: O código inicial já existe e precisa ser refatorado para ficar mais legível, testável e aderente aos princípios de Clean Code e SOLID.

Instrução para o assistente IA:
- Revise a implementação atual e proponha refatorações pontuais para reduzir acoplamento, melhorar nomes, extrair responsabilidades e simplificar fluxo de controle.
- Preserve comportamento e priorize mudanças pequenas e seguras.

Saída esperada:
- Lista de refatorações recomendadas.
- Código refatorado ou diffs exemplificando antes/depois das principais melhorias.
